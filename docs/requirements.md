It must be possible to specify match date as parameter
Date format is dd-mm-yyyy
Default start time is 09.00
Default end time is 12.00
A RESUL CUP is created for provided date.
- example event: https://shootnscoreit.com/event/136/108/
Cup scoring_mode should be "series-points is same as component-match points" (pts)
Cup and Match max competitors is 25
Cup allowed categories is 'Open'
Cup results are shown only to participants
Cup competitor will be automatically registered to all Cup Matches
Registration will start one week before the Cup.


for each Cup, three matches are created with following names:
- one for "Tarkkuus"
- one for "Pika"
- one for "Kuvio"

Individual matches are following type:
25m Pistooli Kuvio
End point: https://shootnscoreit.com/nordic/create-resul-25-kuvio-pistol/

Match name is in format "Kupittaa dd.mm.yyyy <name> 

"Tarkkuus" example:
https://shootnscoreit.com/event/91/1753/

"Pika" example:
https://shootnscoreit.com/event/91/1754/

"Kuvio" example:
https://shootnscoreit.com/event/91/1755/"

Matches belong to the Cup event.

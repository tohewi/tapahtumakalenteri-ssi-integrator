# Kupittaa Cup Creation - Developer Process Guide

This guide describes the technical process for creating a Kupittaa RESUL CUP with matches and squads on Shoot'n'ScoreIt (SSI).

## Overview

The creation process follows these steps:

```
1. CHECK DUPLICATES → 2. CREATE CUP → 3. CREATE MATCHES → 4. LINK MATCHES TO CUP → 5. CREATE SQUADS
```

## Prerequisites

- PowerShell 7.0+ (pwsh)
- `powershell-yaml` module (`Install-Module powershell-yaml`)
- Valid SSI session ID (browser cookie)
- Configuration file: `config/kupittaa-cup-config.yml`

## Process Flow

### Step 1: Check for Duplicates

Before creating any events, the script checks `/my-events/` page for existing events with the same name.

```powershell
function Test-EventNameExists {
    # Fetches user's events page and checks if event name already exists
    $myEventsResponse = Invoke-WebRequest -Uri "$BaseUri/my-events/" -WebSession $Session
    if ($myEventsResponse.Content -match [regex]::Escape($EventName)) {
        return $true
    }
    return $false
}
```

### Step 2: Create RESUL CUP

**Endpoint:** `POST /series/nordic/create-resul-cup/`

**Key Fields:**
| Field | Value | Description |
|-------|-------|-------------|
| `group` | 25874 | Management group ID |
| `name` | TurRes Kupittaa CUP {date} | Cup name |
| `scoring_mode` | pts | Points-based scoring |
| `match_registration_mode` | all | Auto-register to all matches |
| `visibility` | pub | Public (for auto-approve) |
| `registration` | op | Open registration (auto-approve) |
| `categories` | Open | Single category |
| `max_competitors` | 25 | Maximum participants |
| `reg_close_date/time` | 12h before start | Registration closes 12h before Cup |
| `url` | Club website URL | Web address link |
| `url_display` | Lisätietoa | Link display text |
| `venue` | Kupittaan urheiluhalli... | Location name |

**Output:** Cup URL containing `TypeId` and `EventId` (e.g., `/event/136/108/`)

---

### Step 3: Create Child Matches (×3)

**Endpoint:** `POST /nordic/create-resul-25-kuvio-pistol/`

Three matches are created:
1. **Tarkkuus** - Precision shooting
2. **Pika** - Rapid fire
3. **Kuvio** - Pattern shooting

**Key Fields:**
| Field | Value | Description |
|-------|-------|-------------|
| `group` | 25874 | Same management group as Cup |
| `name` | Kupittaa {date} {suffix} | Match name |
| `verify_using` | xxx | No verification required |
| `reg_start_date/time` | Same as Cup | Registration synced with Cup |
| `reg_close_date/time` | Cup end date/time | Registration closes when Cup ends |
| `ends_date/time` | Cup end date/time | Match ends when Cup ends |
| `sq_start_date/time` | Reg start date/time | Squading starts with registration |
| `sq_close_date/time` | Match start date/time | Squading closes at match start |
| `venue` | Kupittaan urheiluhalli... | Location name |
| `description` | From config | Match-specific description |

**Output:** Match URLs containing `TypeId` and `EventId` for each match

**Note:** Venue coordinates (lat/lng) cannot be set via form - must be added manually via SSI map UI.

---

### Step 4: Link Matches to Cup

**Endpoint:** `POST /event/{cupTypeId}/{cupEventId}/add-existing-match/`

Each match is linked to the Cup as a component:

| Field | Value |
|-------|-------|
| `number` | 1, 2, 3 (sequential) |
| `match` | Match EventId |
| `included` | on |

---

### Step 5: Create Squads (×3 per match)

**Endpoint:** `POST /nordic/match/{matchId}/add-squads/`

Three squads per match:

| Squad Name | Max Shooters | Description |
|------------|--------------|-------------|
| Oma ase 1 | 9 | Own firearm |
| Oma ase 2 | 9 | Own firearm |
| Laina-ase | 7 | Loaner firearm |

**Key Fields:**
| Field | Value | Description |
|-------|-------|-------------|
| `quantity` | 1 | Create one squad |
| `max_competitors` | 9 or 7 | Max shooters per squad |
| `registration` | aa | Auto-approve squad registration |
| `comment` | Squad name | Descriptive name |
| `categories` | - | All categories |
| `starts_date/time` | Reg start | Squad registration start |

**Note:** Squad names are auto-generated by SSI. The `comment` field is used for descriptive names.

## Authentication

SSI uses Django session-based authentication:

1. **Session Cookie:** `sessionid` - Obtained from browser after login
2. **CSRF Token:** Retrieved from form page before each POST request (except squad creation)
3. **Language Cookie:** `django_language=en` - Ensures English responses

```powershell
$session = New-Object Microsoft.PowerShell.Commands.WebRequestSession
$session.Cookies.Add((New-Object System.Net.Cookie("sessionid", $SessionId, "/", "shootnscoreit.com")))
$session.Cookies.Add((New-Object System.Net.Cookie("django_language", "en", "/", "shootnscoreit.com")))
```

**Important:** Squad creation endpoint does NOT require CSRF token.

---

## Error Handling

### Common Issues

1. **CSRF Token Missing:** Always fetch fresh token before each POST (except squads)
2. **Redirect Loop:** Check if form validation failed (stayed on same page)
3. **Missing Required Fields:** SSI returns to form with error messages
4. **Time Format:** Use InvariantCulture for HH:mm format (Windows locale may use dots)
5. **Duplicate Names:** Script checks `/my-events/` before creation

### Debug Strategy

```powershell
# Save response HTML for inspection
$response.Content | Out-File -FilePath "debug-cup-response.html" -Encoding UTF8
```

## Configuration Reference

### `kupittaa-cup-config.yml` Structure

```yaml
management:
  groupId: "25874"      # Management group (or "xxx" for self-administered)
  organizerId: ""       # Organizer (empty for no club)

cup:
  nameTemplate: "TurRes Kupittaa CUP {displayDate}"
  description: "..."    # Max 300 chars
  information: "..."    # Max 800 chars (detailed info)
  startTime: "09:00"
  endTime: "12:00"
  registrationDaysBeforeEvent: 7
  url: "https://..."    # Web address
  urlDisplay: "Lisätietoa"
  venue: "Kupittaan urheiluhalli..."

match:
  nameTemplate: "Kupittaa {displayDate} {matchSuffix}"
  verifyUsing: "xxx"    # No verification
  venue: "Kupittaan urheiluhalli..."

matchTypes:
  - suffix: "Tarkkuus"
    description: "SAL 25m pistooli..."
  - suffix: "Pika"
    description: "SAL 25m pistooli..."
  - suffix: "Kuvio"
    description: "Lyhennetty RESUL..."

squads:
  definitions:
    - name: "Oma ase 1"
      maxShooters: 9
    - name: "Oma ase 2"
      maxShooters: 9
    - name: "Laina-ase"
      maxShooters: 7
```

## Example Usage

```powershell
# Production
.\New-KupittaaCup.ps1 -Date "25-01-2026" -SessionId "your-session-id"

# Test mode (adds TEST prefix)
.\New-KupittaaCup.ps1 -Date "25-01-2026" -SessionId "your-session-id" -TestMode
```

This creates:
- 1 RESUL CUP
- 3 Matches (Tarkkuus, Pika, Kuvio)
- 9 Squads (3 per match)

All linked and configured according to `kupittaa-cup-config.yml`.

---

## Known Limitations

- **Venue coordinates** cannot be set programmatically - must be added via SSI map UI
- **Event deletion** must be done manually via SSI web interface

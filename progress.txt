# Ralph Progress Log

## Codebase Patterns
- **Module Boundaries (`AGENTS.md`)**: Routes (`scoring-proxy/routes/*.js`) may only import their domain module from `lib/ssi-core/*.js`, their service module from `lib/services/*.js`, and shared utilities (`logger`, `errors`, `middleware`). Domain modules in `lib/ssi-core/*.js` may only import `http-helpers.js`.
- **File Size Guideline**: Keep files under ~500 lines. Extract route business logic into `scoring-proxy/lib/services/` and UI sub-components into `scoring-ui/src/components/<page>/`.
- **Logging Discipline**: Always use `import { log } from '../lib/logger.js'` (`log.info`, `log.warn`, `log.error`, `log.debug`) in backend routes, services, and middleware — never raw `console.*`.
- **Agent Instructions Sync**: Any update to `AGENTS.md` must be mirrored identically in `.github/copilot-instructions.md`.
- **Frontend Test Runner on Windows**: Run `npm test -- --maxWorkers=1 --pool=threads` in `scoring-ui` for reliable single-worker execution.
